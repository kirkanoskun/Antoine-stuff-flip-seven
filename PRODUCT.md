# Product

## Register

brand

## Users
Joueurs autour d'une table pendant une partie de Flip 7. Contexte : mobile posé sur la table, une main libre, lumière variable. Usage occasionnel (quelques fois par semaine). Familiers avec les jeux de cartes, pas nécessairement tech-savvy.

## Product Purpose
Suivre les scores en temps réel pendant une partie de Flip 7. Calcul automatique des points depuis les cartes, historique des manches, détection du gagnant. Le téléphone disparaît dans le jeu — il ne doit jamais ralentir la partie.

## Brand Personality
Énergique, ludique, précis. Le jeu lui-même : couleurs franches, typographie grasse, rythme rapide.

## Anti-references
- Applications ternes type "notes" ou "calculatrice" système
- Interfaces corporate / SaaS neutres (gris, blanc, Inter 14px)
- Flat design sans personnalité (Material Design basique)

## Design Principles
1. **La partie d'abord** : chaque interaction doit être faisable en 2 secondes, une main, debout.
2. **Le score est roi** : le nombre de points doit être le premier élément vu à l'ouverture.
3. **Fidèle au jeu** : couleurs, typographie et énergie doivent rappeler la boîte physique.
4. **Zéro friction** : aucun état vide non guidé, aucune action irréversible sans confirmation.
5. **Délice mesuré** : les micro-interactions existent pour confirmer les actions, pas pour décorer.

## Accessibility & Inclusion
- WCAG AA minimum sur toutes les combinaisons texte/fond
- Touch targets ≥ 44×44px (usage mobile exclusif)
- `prefers-reduced-motion` respecté sur toutes les animations
- Pas de dépendance à la couleur seule pour véhiculer une information
